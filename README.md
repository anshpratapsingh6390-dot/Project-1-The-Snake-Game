# Project 1 - The Snake Game

A classic Snake Game built using HTML, CSS, and Vanilla JavaScript.

## Features
- **Score & High Score Tracking**: Saves your high score locally using `localStorage`.
- **Timer**: Displays elapsed time during gameplay.
- **Responsive Controls**: Navigate the snake using arrow keys.
- **Game Modals**: Clean start and game-over screens with restart functionality.

## How to Run
1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Click **Start Game** and use the arrow keys to control the snake!
